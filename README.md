# Qaz-Kelem · Support Copilot (Grand Mobile × Decentrathon 6.0, кейс 03)

Веб-демо сервиса триажа обращений игроков: язык (kk/ru/en/uz), категория, приоритет,
спам и дубли, извлечение фактов, черновик ответа с цитатами правил, флаг «нужен человек».

## Что есть
- Контракт ответа как у POST /triage (JSON в карточке обращения)
- Восстановление казахских букв из cp1251 (ќ→қ, ґ→ғ и др.)
- Цитируются только существующие пункты; платежи, взломы и апелляции всегда человеку
- Интерфейс админа: отправить, править, эскалировать; правки сохраняются как обучающий сигнал
- Сроки ответа (SLA), уведомления, 100 демо-обращений, интерфейс RU / KZ / EN

## Запуск
Откройте index.html в браузере. Бэкенд не нужен.

## Ограничения
- Работает в браузере на правилах и шаблонах, без бэкенда: HTTP-сервиса POST /triage и make predict нет
- База правил учебная, rules.json и taxonomy.json не использовались
- Метрики на валидации не считались; шаблоны kk/uz не проверены носителями
- Данные организаторов в репозитории не используются
